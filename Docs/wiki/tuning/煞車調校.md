# 煞車調校

> **🚲 用比喻理解**：煞車調校像分配腳踏車**前後煞車力**——
>
> - **平衡偏前**：重煞時重量本來就壓到前輪，前輪能承受更多煞車力；太多會讓前胎忙到沒力轉彎，形成推頭
> - **平衡偏後**：後輪分到更多煞車力，入彎會更願意轉；太多時後胎先滑，車尾容易甩出去
> - **煞車壓力**：像握煞車把的力道上限。太高會更容易鎖死，太低則煞車距離拉長
>
> **賽車技巧**：在彎前**重煞**（壓力高）、進彎前**鬆開**（trail brake）——煞車調校只是把這個過程的「**比例**」調到順手。

> **修訂 2026-04-21**：從《萌新攻略第九期》補入**公路／拉力／越野「一律不改」**的強烈觀點；**漂移煞車力度**兩份來源有衝突，已改為併列呈現。

解鎖煞車調校一般是**高性能賽車**。可加大煞車力度，更晚進煞車點、搶入彎路線。一般車輛解鎖此項可不調。

## 制動力分布（前 / 後）

> ⚠️ **關於「中英文 UI 方向相反」**：FH5 的煞車平衡滑桿在**中文版與英文版顯示方向是反的**。本 wiki 全文以**中文版 UI** 為準（往左 = 偏前 = 滑桿百分比小、往右 = 偏後 = 滑桿百分比大）。
>
> 收錄的 4 家中文社群來源（地平線5 調校教學、萌新攻略第九期、QuickTune、硬核調校指南）皆按中文 UI 描述；4 家英文社群來源（HokiHoshi 2025、HokiHoshi 2021、HokiHoshi 2021 漂移、Johnson Racing 2025）皆按英文 UI 描述——**兩邊各自描述都正確**，只是 UI 方向不同。
>
> 看英文教學時請**反向讀**：英文作者說「shift to rear（54% rear）」≈ 中文版的「偏前」；英文作者說「往 front」≈ 中文版的「偏後」。**最可靠的驗證方法是自己實測煞車時鎖死的是哪一軸**。

- **完全往前** → 只前輪煞車
- **完全往後** → 只後輪煞車

### 偏前 vs 偏後

| 分布 | 手感 | 效果 |
|------|------|------|
| 偏前 | 前輪負責更多減速，車身較穩，但前胎容易忙到不想轉 | 穩定，過多會推頭 |
| 偏後 | 後輪分到更多減速，車尾更容易開始旋轉 | 入彎靈活，過多會甩尾 |

一般應**偏前**，建議適量調小，但**偏移不超過 5 %**，否則煞車時可能失控甩尾。

## 煞車力度

- 想要更短煞車距離 → 調高
- 力度過高 → **車輪抱死**，反使距離更長、更易失控、易進入漂移

### 公路 / 拉力 / 越野

兩份來源的立場：

| 來源 | 建議 |
|------|------|
| 調校教學 | 解鎖此項可加大煞車力度（上限 **125 %**，初始 **115 %**）|
| 萌新攻略第九期 | **一律不改**，改了反而**爆死（撞車）機率變大** |

> 實際建議：「會改再改，不會改就別動」。初學者保守派遵循第九期不改；熟手可按調校教學的範圍微調。

### 漂移車（併列：三份來源數值不同）

| 來源 | 漂移煞車力度 | 備註 |
|------|-------------|------|
| 調校教學 | **130 %** | 更快進入漂移打滑 |
| 萌新攻略第九期 | **100 ~ 110 %** | 依煞車手感微調 |
| HokiHoshi 2021（**tandem 用**）| **30 %** | tandem 中跟車太近時可踩煞車減速而不拉直車身；同時把煞車偏置移向**前輪** |

差異可能反映不同漂移情境（一般 drift zone vs tandem 跟車）與車型偏好——建議依自己試車手感選取。

> 註：HokiHoshi 的「偏置往前輪」是按英文 UI 描述（英文版滑桿方向與中文版相反），讀者用中文版時請反向操作——往中文 UI 的「偏前」方向移動即可。詳見本檔開頭「中英文 UI 方向相反」說明。

## 硬核版：依控制器類型細分

| 控制器 | 制動力建議 |
|-------|-----------|
| 手柄 / 方向盤（無 ABS，後驅） | **60 ~ 80%** |
| 鍵盤（後驅） | **60 ~ 80%** |
| 開啟 ABS | **80 ~ 200%** 都可，比較靈活 |

### Mustuff124 第 5 家補充（無 ABS 用）

| 玩家狀況 | 制動力 |
|---------|-------|
| **開 ABS**（作者自己）| **不調**（保留原廠／預設）|
| **不開 ABS** | **90 ~ 130%**，看自己手感 |

> Mustuff124 的「無 ABS 90~130%」**比硬核版的 60~80% 高**——可能反映不同手感偏好或 build 類型。**建議實驗**：先用硬核版 60~80% 的低力度路線（重視循跡剎車與精細控制），若覺得煞車距離過長，再朝 Mustuff124 的 90~130% 高力度路線試。

### 制動力邏輯

- **制動力低** → 增加剎車動作行程，對**循跡剎車與精細控制**有利
- **制動力高** → 增加剎車力度、減少行程

### 剎車平衡特例

| 情境 | 建議 |
|------|------|
| 一般車 | **> 50%**（偏前 → 增轉向過度；偏後 → 減轉向過度、增轉向不足）|
| 天生轉向靈活的車（如第六元素特別版、CCGT）| 可設 **< 50%** 以提升剎車穩定性 |
