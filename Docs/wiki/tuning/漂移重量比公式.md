# 漂移車重量比套用公式

漂移車的**防傾桿 / 彈簧 / 阻尼**較特殊，不是固定值，而是依**車輛前後重量比**推算。

## 公式

```
(最大值 − 最小值) × 重量比 + 最小值
```

### 步驟

1. **進入選車界面**查看車輛前後重量比（例：前 48 % / 後 52 %）
2. 依上方公式計算
3. 套用規則：
   - 要改「**前側**」的數值 → 用**前側**重量比
   - 要改「**後側**」的數值 → 用**後側**重量比

## 套用範例

假設某車前重量比 **48 %**，某滑桿最小 **10**、最大 **60**：

- 前側數值 = `(60 − 10) × 0.48 + 10` = **34**
- 後側數值 = `(60 − 10) × 0.52 + 10` = **36**

同一條公式套給**防傾桿、彈簧、阻尼**的前後兩側滑桿。

## 方向性原則（HokiHoshi 2021）

> 中文社群給的是**重量比公式**——從車輛物理屬性算出基準值。
>
> HokiHoshi 給的是**方向性偏好**——「往哪邊調對漂移有利」。兩者**互補不衝突**：先用公式定基準，再依以下原則微調。

### 阻尼

| 項目 | 建議 |
|------|------|
| **回彈（Rebound）** | **原廠通常就夠**——不必動 |
| **壓縮（Bump）** | **設為回彈的 50%**——讓胎在漂移中黏住路面 |

> 這是漂移專屬的**比例關係**——非漂移調校通常 bump 與 rebound 接近。

### 彈簧

| 部位 | 建議 |
|------|------|
| **前彈簧** | **盡量別動太多** |
| **後彈簧** | **更軟 = 後胎抓地更多**——高動力 build 最有用 |

### 車高

> 「**lift 漂移車是褻瀆**」（lifting a drift car is sacrilege）—— **車高設最低**。

### 防傾桿（後 ARB 二分法）

> 後 ARB 對漂移的影響**依動力等級反向**——低動力與高動力 build 朝相反方向調：

| 動力等級 | 後 ARB 方向 | 為什麼 |
|---------|------------|-------|
| **低動力 build** | **更硬** | 更容易把後輪甩出來 |
| **高動力 build** | **更軟** | 後抓地大增——高動力 build 已經夠容易甩，需要靠 ARB 保 grip |

> **前 ARB**：盡量別動太多（與彈簧前段一致）。

### 與公式的整合

1. 先用**重量比公式**算出 ARB／彈簧／阻尼的**基準值**
2. 再依本節原則**微調方向**：
   - 後 bump 阻尼 → 收到 rebound 的 50%
   - 後彈簧 / 後 ARB → 依動力等級往一邊偏
   - 車高 → 直接降到底

> 這對應 [漂移基礎 § 抓地對偶速查](../driving/漂移基礎.md#tune-層級抓地對偶速查) 的「想要更多／更少後抓地」對偶——本節是**漂移基準 build 的方向**，對偶表是**運行時微調的方向**。
