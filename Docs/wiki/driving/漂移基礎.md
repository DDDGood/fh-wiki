# 漂移基礎

> **🎢 用比喻理解**：漂移不是放任車失控，而是把後輪維持在**可控滑移角**——
>
> - 像滑冰選手用刀刃側滑轉向：看似滑出去，但每一刻都在控制角度、速度與重心
> - **油門才是真正的方向盤**——多一點油 = 推到彎外、少一點 = 拉到彎內、腳煞 = 削速 + 拉內、手煞 = 鎖後輪延長 drift
> - **抓地遊戲**：高動力 build 幾乎所有調整都在「**最大化後胎抓地**」，反直覺但對
>
> **核心心法**：「**沒有 mod 比座位時間更值錢**」（no mod is more valuable than seat time）。漂移是動態技能，沒有按鍵組合可按。

> 本檔聚焦**駕駛技巧**——漂移的調校與改裝細節分散在這些檔，可交叉參考：

> - 差速器（全焊 vs LSD 範圍） → [差速器](../tuning/差速器.md#關於漂移車的差速器)

## 一、漂移前必要設定

### 遊戲輔助

| 項目 | 設定 | 為什麼 |
|------|------|-------|
| **Stability Control（穩定控制）** | **關** | 系統會主動干預修正方向，根本飄不起來 |
| **Traction Control（循跡控制）** | **必關** | 同上，會切油門 |
| **變速箱** | **至少 Manual Clutchless（手動無離合）** | 自動排檔極難漂移；手動有離合可額外 clutch kick（新手非必要） |
| **Steering** | **Normal**（新手） | Simulation 雖然真實但反打更難 |
| **ABS** | 新手保留 | — |

### 控制器死區

> **控制器派 RWD 玩家**通常會把死區放寬到 **inner 5 / outer 95**，讓「低油門 → 高油門」的行程**長很多**——漂移要靠**節流踏板控制角度**，行程越多越好控。

詳見 [駕駛輔助與輸入設定](../settings/駕駛輔助與輸入設定.md)。

## 二、漂移的四個環節

| 環節 | 內容 |
|------|------|
| **Line（路線）** | 入彎切角度與軌跡——練熟一個彎再延伸 |
| **Entry（入彎）** | 用什麼方式把車重甩出去——**新手用手煞車入彎**，熟練後改用重量轉移 |
| **Drift（中段）** | 反打 + 油門控速 + 視需要點手煞車延長 |
| **Exit / Transition（出彎或過渡）** | 油門平順放，過渡到下一彎或拉直 |

> 練習地點：**主節慶區的 Drift Zone**——彎道大、容錯高。

---

## 三、入彎：手煞車入彎（新手起手式）

> 手煞車入彎是「**新手拐杖**」——容易上手，但熟練後要逐步**減少**使用手煞車（改用重量轉移）。

### 步驟

1. 直線朝彎切入
2. **轉向 + 同時拉手煞車**
3. **手煞車保持拉住** + **看到車重轉移就立刻反打（counter-steer）**
4. **不要碰油門**——只用手煞車與反打維持彎中前進，直到停下來
5. 全程**車頭朝彎道出口**

### 自我診斷

| 結果 | 診斷 |
|------|------|
| 停下時車身與橋平行 | 大概做對了 |
| 持續打轉（spin out） | **反打太晚 / 反打不夠** |
| 入彎太快 / 太外 | **手煞車拉太多** |

### 然後才開始加油

能穩定不打轉之後**才加油**，且**只在需要時加**：

- 速度自然慢下來、滑了一下後 → 加油拉回來、推出彎
- 加油就撞紅線 → **檔位太低**，升檔
- 加油就 bog down（無力） → **檔位太高**，降檔

---

## 四、中段：反打 + 油門控速

### 反打（counter-steer）

無系統教法，靠 **timing 與練習**：

- 你會慢慢學會預判：**入彎時車會走多大角度**
- 預判後，**幾乎要先反打、不是事後反打**
- **新手最常見錯**：**反打太晚**——車已經太深 spin 中救不回來

#### 控制器 vs 方向盤

| 工具 | 反打手感 |
|------|---------|
| **控制器**（Xbox 控制器） | 大量「**敲擊 → 回正 → 再敲擊**」的微反打——拇指要忙 |
| **方向盤** | 平滑連續微調——更接近真實漂移 |

### 「油門才是真正的方向盤」（核心心法）

| 動作 | 效果 |
|------|------|
| **多油** | 增速 + 增加角度 + **把車推到彎外** |
| **腳煞** | 降速 + **把車拉到彎內** + 削 wheel speed |
| **手煞車** | 鎖死後輪 + **在需要時延長 drift** |

> 多數人以為漂移就是「**側滑後猛踩油門**」——錯。**漂移大量需要 feathering（半油）**，只在需要更多角度或速度時才加油，否則讓車自己滑。

### 手煞車中段用法

別只當入彎工具——drift 中**也能用**：在需要**延長 drift** 或補抓地不足時鎖住輪子。

---

## 五、出彎與過渡

| 動作 | 結果 |
|------|------|
| 油門**突然放掉** | 抓地突然回來 → 車身重量甩過去 → **spin out** |
| 油門**緩慢放 / 半油門過渡** | 重量平順轉移，順利拉直或進下一彎 |

---

## 六、練習路徑

> 漂移要耐心——按這個順序循序漸進：

1. **單彎反覆**：找一個彎練到幾乎每次都能 nail
   - 入彎速度 / 角度
   - 何時加油
   - 何時反打
   - 怎麼跟線
2. **跨彎連續**：地圖換另一區，**串連多個彎**
3. **改用重量轉移入彎**：熟練後**捨棄手煞車**作為主要入彎方式

---

## 七、排錯：抓地對偶（Build × Tune × 駕駛）

> **90% 問題能用更好的油門控制 + 反打解決**——先檢查駕駛，再調 build／tune。

### 駕駛層級

| 症狀 | 處方 |
|------|------|
| 老是 spin out | 反打更早；油門控制（先鬆點再加） |
| 一直推頭抓不出 drift | 入彎更晚轉、手煞車拉久一點 |
| 中段角度撐不住 | 加油時機晚一點、油量小一點 |
| 出彎被甩飛 | 油門**慢慢**放、不要瞬放 |

### Build 層級

| 症狀 | 處方 |
|------|------|
| **新手一直 spin out** | **先加 grip** 直到舒服，再慢慢拿掉 |
| 完全不滑 | grip 太多，反向操作 |

### Tune 層級：抓地對偶速查

> 這是**漂移 tune 的核心對偶**——所有「抓地相關旋鈕」都遵循同一方向。

| 想要 | 方向 |
|------|------|
| **更多後抓地** | 降低／放軟下列任一：後 bump 阻尼 ↓、後彈簧剛性 ↓、後 ARB ↓、後胎壓 ↓、差速器 accel/decel 鎖 ↓ |
| **更少後抓地** | 把上面**全部反向**加硬／加大 |

### tandem 特殊考量

tandem 中常**故意促進更少抓地**——避免追車中突然抓回來而：
- 失去 drift
- 撞到 lead driver

---

## 八、漂移 vs Healthy Oversteer

> 兩者**不要混淆**——詳見 [賽車線與彎道基礎 § Healthy Oversteer](./賽車線與彎道基礎.md#五healthy-oversteer--slip-angle進階)：

| 概念 | 滑動程度 | 速度 | 用途 |
|------|---------|------|------|
| **Healthy Oversteer** | 微 slip angle | **更快** | 競速（單圈最佳） |
| **Drift** | 大幅滑動 | 較慢 | **視覺與分數**（drift zone / drift score） |

> 漂移是**為了視覺與分數**，不是為了單圈最快。
