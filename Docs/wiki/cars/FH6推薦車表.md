# 🏁 FH6 推薦車表（各等級各賽事）

> 本表是 **長期維護** 的 FH6 線上競爭力車單，按 PI 等級（C/B/A/S1/S2/R）× 賽事類型（公路街頭 / 泥地拉力 / 越野）分節。每車記錄：競爭力分級、廠商、車型、驅動、難度、輪胎類型、定位、**獲取方式**、備註。後續收錄到的新來源都會擴充進此表，不另開檔。

::: tip 本作 PI 等級系統
**FH6 新增 R 級**：本作將最高等級擴充為 **R 998**（前作 FH5 最高為 X 999）。完整等級：**C 500 → B 600 → A 700 → S1 800 → S2 900 → R 998**。
:::

::: warning 表格目前的調校師來源
本表所有調校都來自 **NOAMIAKO**（線上表格署名 `Noa Miyako`），於 FH6 上市前 4 天（2026-05-15）由 XBOX 邀請提前 150 小時試玩後整理。**競爭力分級僅代表 NOAMIAKO 的視角**。日後收錄其他作者的調校與車單時，會在本表加回「調校師」欄位。
:::

## 📖 表格欄位定義

### 競爭力分級

| 標記 | 含義 |
|---|---|
| **Meta+** | 最強，本等級該賽事類型的當前主力車選 |
| **Meta** | 強，可與 Meta+ 競爭、僅次一線 |
| **T1** | 一級替代，特定圖或特定駕駛風格仍有優勢 |
| **T2** | 二級替代，可玩性 OR 樂趣導向 |
| **T3** | 三級，明顯非主流 |
| **未知** | 作者尚未完整測試或不確定定位 |

### 輪胎類型對照

| 輪胎 | 對應遊戲內 | 主要場景 |
|---|---|---|
| **原廠胎**（Stock） | 出廠原配 | 復古車保留原味；低 PI 等級唯一選項 |
| **街車胎**（Street） | Street Tires | 公路通勤車泛用，平衡 |
| **復古白胎**（Vintage Race） | Vintage Race Tires | 1960 年代前車種專用復古熱熔，公路抓地強 |
| **拉力胎**（Rally） | Rally Tires | 公路 / 泥地過渡，泛用 |
| **漂移胎**（Drift） | Drift Tires | 漂移專用，公路圈速也可用 |
| **直線胎**（Drag） | Drag Tires | 縱向抓地超強，**僅限乾燥路面**，犧牲橫向 |
| **越野胎**（Off-Road） | Off-Road Tires | 泥地 / 越野通用 |
| **半熱熔**（Sport） | Sport Tires | 可在輕度積水路面使用 |
| **全熱熔 / 賽用熱熔**（Race） | Race Slick | 圈速最強，**僅限乾燥路面** |

#### 🗺️ 區域刷新：地圖購車點位

> 地圖上散布 **約 20+ 個改裝車購車點位**，是除了車庫、Autoshow、賽事獎勵、Wheelspin 之外的另一個取車管道。

**三台「其他渠道難以取得、固定刷出特別版」的稀有車**：

| 車輛 | 出現點位 | 備註 |
|---|---|---|
| **Subaru BRZ 極限競速特別版** | **阿爾卑斯山附近的山區購車點**（NOAMIAKO 影片稱「外山區」） | S1 泥地/越野 Meta+ |
| **Mazda MX-5 Miata Forza Edition** | **嘉年華（Carnival）直線加速賽道盡頭**（NOAMIAKO 影片稱「大鼓區嘉年華旁」） | 「這代的畢業神車」；S1/S2 公路 Meta+ |
| **Mazda RX-3 特別版** | **「大黑趴」點位**（大型 Car Meet 區） | NOAMIAKO 車表未列，待後續驗證競爭力 |

**點位刷新機制**（未經官方確認，UP 主觀察結論）：

1. 每個點位有**固定的車輛刷新列表**——特定車型只在特定點位刷出
2. 每次點位**實際出哪一台是隨機的**；有時點位「暫時空著」
3. 刷新頻率與次數也是隨機的
4. 看起來是**線上行為**，斷線可能不刷
5. 可能**隨 Series 換季變動**車輛池

**強制刷新技巧**：
- 把點位現有的車**買掉**，下一次它就會刷出新的
- 若刷出百萬等級超跑（例如 Koenigsegg CCGT）前期買不起，只能等自然刷新

**購買優惠**：
- 購車點位的車輛有折扣，**目前觀察到最高折扣為 35%**
- 點位刷出的「改裝版」車輛**性能與原廠版有區別、會更快**（例：S2000 改裝版比原廠 S2000 快）；同點位有時刷改裝版、有時刷原廠版，**購買時需仔細辨別**

**點位分布原則**（依當地場景調性）：

| 區域類型 | 會刷的車種 |
|---|---|
| **大黑趴**（街道聚集區） | 街車、改裝車（含 RX-3 特別版） |
| **賽道區**（北部計時、體育場周邊） | 跑車、賽車、超跑 |
| **嘉年華區** | S 級車、直線加速車（含 Miata FE） |
| **漂移賽道區** | 漂移車 |
| **體育場下方點位** | **連刷三台車**（同點位三車並列） |

**新手期建議**：只要買得起的都儘量買；點位刷出價格不超過百萬就值得入手；改裝版可直接拿去跑比賽，省去自己慢慢改車的時間。

### 定位 / 難度

- **定位**：`全能` / `動力` / `操控`
- **難度**（由易至難）：`非常簡單` → `簡單` → `中等` → `稍微困難` → `困難` → `非常困難`

> 難度多由 **驅動方式**（AWD < RWD < FWD 大馬力）與 **馬力**（高馬力 RWD 經典款最難）決定。

## 🎮 駕駛手感變化（vs FH5）

NOAMIAKO 高強度試玩後最明顯的感受：**車的回饋變得更細膩**。

- **FH5**：開起來像輪胎吸著路面在跑；推頭、甩尾、抓地恢復都來得比較突然。
- **FH6**：能明顯感覺到車身與懸吊的運動／變化；輪胎從抓地到打滑中間有更自然的過渡；車輛與地面的連結更加緊密。

對調校的影響：細膩的物理引擎讓**輕量化老車**（Beat、Sports 800、Civic、Charger 等）在 Meta+ 名單占比顯著提升，後驅復古肌肉車雖然難度高但圈速極具競爭力。
