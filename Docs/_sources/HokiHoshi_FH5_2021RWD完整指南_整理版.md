## 一、開場：FH5 的 RWD meta 背景

> 作者明說很期待錄這支影片——FH5 對 RWD 做了**大幅進步**。

### 1.1 過去幾代的情況

- **FH4 之前幾代**：AWD 主導 meta
- 雖然好駕駛總能用 RWD 跑出像樣成績，但 AWD 在線上競速**始終有明顯優勢**

### 1.2 FH5 的改變

> 「**FH5 中這已經不是事實——RWD 在合適情境下完全能與 AWD 競爭。**」

#### 真實世界對照

| 驅動 | 強項 | 弱項 |
|------|------|------|
| **AWD** | **緊彎、低抓地情境**佔優；油門可更激進 | 天生**轉向不足** |
| **RWD** | 通常**更輕、能塞更多動力、高速彎更快** | 較難駕馭 |

FH5 把這個對比**忠實搬進遊戲**：

- AWD **仍有定位**、仍**較易駕**
- 多數玩家發現 RWD **在許多情境一樣快或更快**

### 1.3 哲學：難度設定的回報曲線

> 簡單設定 → 易駕但**較慢**
> 硬核設定 → 難駕但**回報是更好的圈速**

> 作者個人認為 RWD **整體更有駕駛樂趣**——尤其方向盤＋踏板，能真正感受到車的極限。

## 二、Build（改裝）

> 整體 build 邏輯沿用作者另一支[通用 build 影片]，本文聚焦 **RWD 專屬例外**。

### 2.1 空力（Aero）

| 級距 | 重要性 |
|------|-------|
| 高級距 | **空力是改善 RWD 操控的關鍵** |
| S1 等 | 仍可能做出**不需要 Forza Aero** 的 build |

理由：RWD 動力只到後輪，**保持抓地更難**——空力幫助後輪持續工作。

### 2.2 胎寬

> **後胎寬在 PI 上極便宜——沒有不取的理由**。
>
> 作者「**幾乎所有 RWD build 都把後胎寬拉滿**」。

#### 前胎寬

- A 組 build 常**有點轉向不足**
- 不想吃 Forza Front Aero 時，**前胎寬是補轉向不足的便宜手段**

#### 寬體（Wide Body）

- 多數車的**寬體**會**解鎖更寬的胎**
- → **寬體在 RWD build 上常常很值得**

### 2.3 胎質（Compound）

| 胎 | 特性 |
|------|------|
| 太低（街道／原廠） | **完全無法把動力輸出到地面** |
| **拉力胎（Rally）** | **絕佳中間選擇**——只比運動稍貴一點 PI，性能接近半熱熔 |
| 半熱熔（Semi-Slicks） | 性能最好但 PI 太貴時用拉力胎替代 |

> 「需要更多 grip 但半熱熔太貴」時記得拉力胎。

### 2.4 輪距交錯（Stagger Wheel Spacing）

**做法**：**後 track width 升級多於前**。
**效果**：過彎時穩定性更好。

#### 作者的起手流程

1. **前後 track width 全部拉滿**
2. 視需要**回降前**寬度來微調過彎手感

### 2.5 變速箱檔數

- RWD 常受益於**更多檔位**
- 5 速 → **升 6 速**；6 速 → **升 7 速**
- 幫助維持在動力區段內 + 更有效輸出

### 2.6 動力曲線：自吸／機增 vs 渦輪

| 動力種類 | 曲線特性 |
|---------|---------|
| **自然進氣（NA）** | **線性平滑** |
| **機械增壓（Supercharged）** | **線性平滑** |
| **渦輪（Turbo）**，特別是**單渦輪** | **底速無力 → 渦輪起來 → 一瞬間爆出大量動力** |

> RWD build 中，作者**偏好 NA 或機械增壓**——爆發太突然容易讓後輪失控。

## 三、Tune（調校）

### 3.1 胎壓（Tire Pressure）

#### 後胎壓

- **降後胎壓**有幾個好處：
  - 幫助 launch
  - 讓後段失控**更平滑、不會突然脫離**
- **建議範圍**：**26–30 PSI 之間找甜蜜點**
- **盯胎溫**：太低／太高都會明顯傷抓地

#### 前胎壓

- 「**通常依需要才動**」——預設多半就剛好
- 有轉向不足時可微降

### 3.2 齒比（Gearing）

#### 最終齒比（Final Drive）

- 多數情況都能調
- **目標**：能在最高檔的接近頂速跑、但仍能達到該級距預期的高速
- **拉長最終齒比 → 幫助維持後輪抓地**

#### 個別齒比

如果有解鎖且**低檔位抓地不夠**：

- 把**1–3 檔拉長**——尤其新手難以控制油門時
- **不要拉太長**，否則犧牲整體加速

### 3.3 四輪定位（Alignment）— RWD 關鍵窗口

> 基礎邏輯沿用 [tuning guide]；本節是 RWD 重點。

| 設定 | RWD 建議 |
|------|---------|
| **前 camber** | **一定要調好** |
| **後 camber** | **盡量低**——但仍要保證**內側 hotter / 外側 cooler** 的胎溫平衡 |
| 後 camber 過低 | launch 變好、但**過彎抓地不足** |
| 後 camber 過高 | launch 變差 |

#### Toe

| 設定 | 用途 |
|------|------|
| **前 toe out 一點點** | 治療轉向不足 |
| **後 toe in 一兩格** | 穩定 launch + 高速直線更穩 |
| Toe 通則 | **只在需要時動**——拉胎溫、降頂速 |

#### Caster

調個人喜好；**動完一定要重檢 camber**。

### 3.4 ARB / 彈簧 / 阻尼（要視為**整體**調）

> 「不能孤立地動：超低前 ARB 配上很硬前彈簧 → 會互相打架。」

#### 平衡邏輯

| 偏向 | 結果 |
|------|------|
| **前更硬** | 出彎好，但**入彎差** |
| **後更硬 / 前更軟** | 入彎快，但**加油時更易甩** |

每位駕駛、每輛車都不同，需要找個人平衡點。

#### 作者偏好的起點

| 車種布局 | 偏好 |
|---------|------|
| **前置引擎** | **低前 ARB + 平衡前後彈簧 + 略硬一點的前阻尼** |
| **中置／後置引擎** | **明顯更軟的前彈簧與阻尼** + **平衡的 ARB** |

### 3.5 車高

- **作者一律降到底**
- 補償方式：**降一點彈簧剛性**避免 bottom out
- 「**FH5 物理中車高的影響沒有它應該有的那麼大**」（作者個人觀察）

### 3.6 下壓力（Aero）

> **目標**：**用越少越好，但仍維持過彎抓地**。

#### 微調流程

| 症狀 | 處方 |
|------|------|
| 轉向不足 | **加前下壓力** |
| 高速尾巴鬆 | **加後下壓力** |
| 兩者都不發生 | **持續減少下壓力直到出現症狀，再加回一格** |

### 3.7 煞車平衡

- **與 RWD 沒太大關聯**——僅在需要時動
- **真要動**的情境：煞車中車子變得 squirrely → 滑桿**往左移一點**

### 3.8 差速器（Differential）

> 一如既往**極為重要**。

#### 加速鎖（Accel Lock）

| 鎖值 | 效果 |
|------|------|
| **低** | 抓地感強、彎中**較不會甩**；但**整體較慢** |
| **高** | 過彎抓地更多、出彎速度更快；但**對突然失抓地、spin out** 更敏感，要平順過彎 |

#### 起手流程

1. **新手 / 油門控制不穩** → 從**低值**起步
2. **熟練後**每次**+20 增量**往上推
3. **多數 build 落在 60–90% accel lock**

#### 減速鎖（Decel Lock）

- **影響較小**，個人偏好為主
- 入彎太靈敏 → **提高 decel lock**

## 四、駕駛技巧

### 4.1 Launch（起步）

> **觀念派系**：
> 1. 直接全油門狂踩，硬撐到抓地回來
> 2. 控制油門、抓地後再全力加速
>
> **實測結論**：**直接全油門最快**。

#### 抓地檢查流程（去拖車道測）

1. **一檔拉到底**——**不換檔**
2. 看**一檔頂速**
3. **真正起步時，速度逼近一檔頂速前一刻升二檔**

#### 範例

> 影片中車一檔頂速 **48 mph** → 起步看儀表，到約 **45 mph** 升檔。

#### 不同級距的合理抓地點

| 級距 | 抓地時機 |
|------|---------|
| **A 組 以下** | 一檔尾段 ~ 二檔早段 |
| **S1 以上** | 二檔尾段 ~ 三檔早段 |

#### 仍打滑

- **三檔還在打滑** → **後胎抓地不夠**：檢查胎質、後胎寬

#### 聲音線索

- 紅線聲音與「**真正達到頂速**」的紅線聲音不同
- launch 中**不該聽到**普通紅線聲

### 4.2 控制器死區（Dead Zones）

> **新版 Xbox 控制器**通常可設：
> - **內側死區 5**
> - **外側死區 95**

效果：**低油門到高油門之間多得多的行程**——RWD 駕馭核心是「不要老是把油門踩到底」。

### 4.3 過彎油門管理（核心技術）

> 用 g 力儀觀察 **重量轉移**：
>
> 1. **煞車** → 重量到**前輪**、離開後輪
> 2. **彎中** → 重量**沿外側輪繞行**
> 3. **出彎** → 重量**回到後輪**

#### 多數人的錯

> **太早 + 太用力踩油門**——重量還沒回到後輪，後輪卻要做功 → **甩尾 / spin**，**高差速器鎖更明顯**。

#### 正確時機

1. **撐到 apex**
2. apex 後**慢慢加一點油**
3. **不要全油，直到 g 力儀顯示「重量已轉到後輪」的範圍**——這時後輪有壓力 + 抓地，才不容易甩

> 實戰中沒有 g 力儀；用練習場 + 儀表培養感覺。

### 4.4 過彎不要彎太多

> **常見錯**：過 apex 後仍然繼續打彎。

#### 正確做法

- 過 apex 後**同時放鬆方向盤 + 開始加油**
- 視覺**瞄向彎外側**，不是內側
- 「**沒有必要轉超過必要的角度**」

## 五、結語

> 「FH5 對 RWD 的提升極大，我喜歡它在線上競速與 Rivals 的可行性。
> 終究 RWD **比 AWD 難**，但**回報更高、讓你變成更好的駕駛**。」
