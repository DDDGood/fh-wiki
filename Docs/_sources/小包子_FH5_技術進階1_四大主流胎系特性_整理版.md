## 一、影片範圍與分類框架

本期以 **S1 車輛** 為基礎，主要講解：

- **熱熔（半熱熔）**
- **直線胎**
- **漂移胎**
- **拉力胎**

四大主流胎系。

UP 主先把這四種胎分為兩大類：

| 類別 | 包含的輪胎 | 主要目的 |
|------|-----------|---------|
| **公路胎類** | 街胎、半熱熔、白胎、懷舊賽車胎 | 均衡為主，盡量不犧牲車輛屬性的前提下強化 |
| **特殊胎類** | 直線胎、拉力胎、漂移胎 | 主要用於降低車輛評分，為後續改裝爭取空間 |

---

## 二、公路胎類

### 1. 整體特性

公路胎類以 **均衡** 為主，在不犧牲過多車輛屬性的前提下進行強化。

### 2. 復古胎 / 懷舊賽車胎

- 多用於將少數特殊車輛 **降級** 的同時 **保留一定公路性能**。
- 主要應用：**B 級與 A 級大馬力後驅車** 的降級改裝。
- 本期不深入講解。

### 3. 半熱熔（熱熔胎）—— 公路胎類重點

| 項目 | 說明 |
|------|------|
| 代表車輛 | **福特 GT 2005**（Ford GT 2005） |
| 主要特性 | 在保留車輛原始直線加速能力的同時 **強化過彎能力** |
| 適用車型 | 1) 原廠過彎能力不足的車<br>2) 不需要降級評分就能改裝的車 |
| 公路性能 | 強 |
| 弱點 | 草坪容易打滑、無排水花紋導致 **雨天／濕地適應差**，需謹慎駕駛 |

> ⚠️ 半熱熔不能隨便往草地踩；下雨天與濕地需特別小心。

---

## 三、特殊胎類（降評分用）

特殊胎主要功能是 **降低車輛評分**，為後續改裝騰出 PI 空間。但三種胎特性差異大，必須依車型挑選。

### 1. 直線胎

| 項目 | 說明 |
|------|------|
| 代表車輛 | **BT62**（Brabham BT62） |
| 外觀特徵 | **後寬前窄** —— 主要用於直線加速 |
| 前輪轉向角度 | **本期四種胎中最大**（前輪窄） |
| 加速能力 | 由於材料特殊，**會增強加速能力** |
| 過彎能力 | **削弱轉向能力**（推極限時容易推頭） |
| 適用車型 | 1) **輕車**：可獲得更大轉向角度，方便快速過急彎<br>2) **原廠就大馬力的車**：搭配後驅改裝，更好地推動力 |
| 不適合 | **重車** —— 容易突破前輪抓地力極限、出現推頭 |

### 2. 拉力胎

| 項目 | 說明 |
|------|------|
| 代表車輛 | **法拉利 FXX**（原音為 FXS，依車型推測為 FXX，請對照遊戲內車庫確認） |
| 性能取向 | **綜合降低車輛整體性能**（加速與過彎平均下降） |
| 適用車型 | 動力與過彎能力都 **較均衡** 的車 |
| 改後手感 | 與原廠較為相似 |
| 特殊優勢 | **雨天／濕地有奇效**（畢竟原本就是泥地用胎） |

### 3. 漂移胎

| 項目 | 說明 |
|------|------|
| 代表車輛 | **Jaguar XJR-15**（捷豹 XJR-15） |
| 特性方向 | 與直線胎相反 —— **捨棄前段直線加速、保留過彎能力** |
| 前輪抓地 | **不錯**（漂移時必須保證前輪抓地以控制方向） |
| 適用車型 | **「AC 車輛」**（原音如此，疑為車型／類別語音辨識錯誤）—— 改裝時直線加速能力不缺、或可捨棄，反而需要保留甚至加強過彎能力的車 |
| 抓地分布 | **橫向與縱向抓地分配反直覺**，會莫名其妙打滑，駕駛時需格外注意 |
| 駕駛要點 | **加速時需仔細控好油門**；油門控制好後，這類車駕駛體驗會「質的飛躍」 |

> 💡 **車型辨識存疑**：原音「AC 車輛」可能是某個品牌、級別或駕馭傳動形式的辨識誤差（如 RWD／重型車／A 級等）。請對照影片畫面或社群討論再行確認。

## 四、四大胎系總結對照表

| 輪胎 | 評分變化 | 加速能力 | 過彎能力 | 越野／雨天抓地 | 其他特色 |
|------|---------|---------|---------|---------------|---------|
| **半熱熔** | **增加** | 增強 | 增強 | **降低**（無排水花紋） | 公路均衡升級 |
| **直線胎** | 降低 | 保留或增強 | **削弱** | — | 大彎角時轉向角度大、車輛靈活 |
| **拉力胎** | 降低 | 均衡降低 | 均衡降低 | **比其他胎稍好**（雨天） | 改後手感接近原廠 |
| **漂移胎** | 降低 | **大幅削弱** | 保留或增強 | — | 常見於 **小圈圖王者** 與 **高速彎王者** 車輛 |

---

## 五、選胎邏輯速記

1. **不想降評分、想強化公路性能** → 半熱熔
2. **想降評分、要直線加速、車輕或大馬力** → 直線胎
3. **想降評分、要均衡、跑泥地或雨天** → 拉力胎
4. **想降評分、走小圈圖／高速彎、不缺直線** → 漂移胎
5. **B/A 級大馬力後驅降級保留公路性能** → 復古／懷舊賽車胎
