## 一、開場

漂移在 FH5 大多取決於 build 與 tune，個人風格也佔很大比重，因此本指南**不像作者其他影片那麼挖細節**——刻意保留個人偏好空間。流程分四段：

1. 漂移車 build（差異：低動力 tandem 與高動力刷分）
2. 漂移車 tune
3. 駕駛技巧（從手煞車入彎開始練）
4. 排錯（troubleshooting）

> 影片本身有時間戳，可跳段觀看。

## 二、Build（改裝）

### 2.1 車種選擇

漂移**唯一硬性要求**：後輪驅動（RWD）。其他偏好：

- **輕量 + 前置引擎**最理想
- 漂移**車種選擇遠不如 build／tune 重要**——對的 setup 可以讓任何車滑起來
- 但底盤天生有強弱：「真實 grassroots 風格」首推 **90s 日系經典**，作者本支用 **FC RX-7**，**S 底盤（S13/S14/S15）**也都是好選
- **高動力刷分 build**：**Formula Drift 車**——有極高轉向角 + 大量動力，刷高分／三星很容易，但**新手用 FD 車起步會很吃力**

> 補充：FH5 之外的開放式漂移車不需符合任何 PI 級距，build 自由度大。

### 2.2 改裝零件

從外觀＋輪圈起手（漂移本來就是風格遊戲）。然後**全套漂移專屬零件**：

| 部位 | 建議 |
|------|------|
| 懸吊 | **Drift Suspension**（漂移懸吊） |
| 差速器 | **Drift Differential**（漂移差速器） |
| 輪胎 | **Drift Tires**（漂移胎） |
| 煞車 | tandem build 一定要 **Race Brakes**——煞車微調是 tandem 關鍵 |
| 變速箱 | 不需高檔位。原廠／Sport／Race 6 速都夠 |

#### 漂移胎的例外

- 部分**低動力 build** 可能用**原廠胎或街道胎**反而合適
- 但作者**自己所有 build** 都選漂移胎當作通用解

### 2.3 動力

**刷分**：越多越好——但要同時加 grip 補回去。
**寫實 tandem**：**350–500 馬力**為主。

> 對照真實世界：作者第一次真實漂移日是 single cam KA-240，僅 ~150 馬力，仍能跑全課程；但 Horizon 的路與彎遠比真實熱門場地大且寬，所以可以放心多塞馬力。

#### 新手起步建議

留在 **350–500 範圍下緣**：
- 太多動力**難以控制**
- 容易養成壞習慣

### 2.4 胎寬（漂移最重要的 build 參數之一）

| 部位 | 偏好 |
|------|------|
| 前胎 | **寬**——保留前胎抓地力，漂移中前胎抓地很重要 |
| 後胎 | **要與動力匹配**，會需要微調 |

**後胎寬與動力的關係**：

- 動力越大 → 越寬後胎
- 太寬 + 太少動力 → **沒辦法維持轉速與輪速**
- 太細 → **持續撞紅線、wheel speed 拉滿但車不動**

> **重要觀念**：漂移本質**還是抓地力遊戲**——尤其高動力 build，幾乎每個調整都在「最大化後胎抓地」。先用胎寬找到對應動力的甜蜜點，再進 tune 視窗微調 grip。

## 三、Tune（調校）

### 3.1 差速器

可選風格：

| 風格 | 加速鎖（accel） | 減速鎖（decel） | 特性 |
|------|---------------|---------------|------|
| **全焊（welded）** | **100%** | **100%** | 兩端都全鎖，**容易、一致地滑出來** |
| **LSD 風格** | **85–95%** | **0–40%**（多數情況） | 寫實派 |

> 作者本人**所有 build 都跑 100% 鎖**——個人偏好。

### 3.2 煞車（tandem 關鍵）

> ⚠️ **FH5 條桿反向坑**：「**Brake Balance** 滑桿在 FH5 是反向的——往條桿『後段』移其實是把偏置移到前輪**。」原文："move all your braking bias to the front wheels which because forza says backwards means towards rear"。
>
> （這條是 FH5 介面的長期 UI 怪癖，社群常踩坑——以條桿視覺方向為準會調反，實際以「車輪」為準。）

| 設定 | 數值 |
|------|------|
| 煞車偏置 | **全部移到前輪**（條桿往後拉） |
| 煞車壓力 | **降到 30%** |

效果：tandem 中如果太逼近 lead driver 可以踩煞車減速，**而不會直接拉直車身把 drift 弄掉**。

### 3.3 下壓力（Aero）

- 沒解鎖空力的 build 可忽略
- **前下壓力高**有助於前段
- 後下壓力 tune 影響不大

### 3.4 阻尼（Damping）

| 項目 | 建議 |
|------|------|
| 回彈（Rebound） | **原廠通常就夠** |
| 壓縮（Bump） | **降到回彈的 ~50%**——讓胎在漂移中黏住路面 |

### 3.5 彈簧（Springs）

剛性大幅影響抓地：

| 部位 | 建議 |
|------|------|
| 前彈簧 | **盡量別動太多** |
| 後彈簧 | **更軟 = 後胎抓地更多**（高動力 build 最有用） |

### 3.6 車高（Ride Height）

> 「**lift 漂移車是褻瀆**」（lifting a drift car is sacrilege）—— **車高設最低**。

### 3.7 防傾桿（ARB）

效果類似彈簧：

| 部位 | 建議 |
|------|------|
| 前 ARB | **盡量別動太多** |
| 後 ARB（低動力 build） | **更硬 = 更容易把後輪甩出來** |
| 後 ARB（高動力 build） | **更軟 = 後抓地大增** |

### 3.8 四輪定位（Alignment）— 漂移最重要的窗口之一

| 設定 | 建議數值 |
|------|---------|
| **前 camber（負外傾）** | **盡量負——多數設定 −5°**（通常已是預設極值） |
| **caster** | **最大 7°**——漂移反打時提供更大角度與抓地 |
| **後 camber** | **甜蜜點 1–1.5° 負**（依車而定） |
| 後 camber 過低 | 會反過來傷整體操控 |
| 後 camber 更負 | **減少**後抓地（要更易甩可這樣調，但不要太誇張） |

#### Toe（束角）

**前 toe out**——增加實際轉向角 + 讓前胎不穩定 → 入彎時更容易把車重甩出去：

| 風格 | 前 toe out |
|------|-----------|
| 寫實 build | **約 2°** |
| 高動力刷分 build | **可拉到 5°** |

**後 toe**——調整後段彎中行為：

| 設定 | 效果 |
|------|------|
| **後 toe out** | 鼓勵更寬的彎道軌跡、**更大 drift 角度**——車像「螃蟹側走」 |
| **後 toe in** | 漂移**更緊、更可控** |

> **新手起步**：用**後 toe in**——幫助巨大；熟練後再往**後 toe out** 推進。

### 3.9 齒比（漂移專用收緊法）

- 低動力寫實 build：**不用太動**
- tandem／高動力 build：**有點蠢但很有用的調法**

#### 步驟

1. 找出**最適合漂移的一檔或兩檔連續檔位**（中動力 build 通常是 **3 檔或 4 檔**）
   - 撞紅線 + 沒在加速 = **檔位太低**
   - 跟不上轉速 + 持續被拉低 = **檔位太高，要降檔**
2. 把**所有更高檔位**「**收緊往下**」貼向那個主漂移檔
3. 圖形應該長得像主漂移檔附近一堆密集檔位

#### 效果

中漂移時可以**自由升降檔**取得：
- 一點額外 wheel speed
- 縮進更緊的彎而不會 bog down

### 3.10 胎壓

| 部位 | 建議 |
|------|------|
| 前胎 | **約 30 PSI**——降低可得到「四輪漂移感」+ 大入彎角度 |
| 後胎 | **微調抓地的主要工具** |

#### 後胎壓邏輯

- **更低 PSI = 更黏、更平滑**
- **更高 PSI = 更突然脫出、漂移中抓地更少**
- **永遠維持原廠 PSI 或更低**——高動力車要更低
- 如果**為了維持 drift 必須把後胎壓拉高過原廠**，代表 build 出問題：可能需要**更硬後段、更細胎、或更多動力**

### 3.11 Build 收尾

> FH5 的漂移專屬零件齊全到一個程度——**任何前置 RWD 車**裝齊全套 drift 零件 + 升到目標動力，就能直接上路；剩下都是個人風格與微調。

## 四、駕駛前的設定

| 項目 | 設定 |
|------|------|
| **Stability Control（穩定控制）** | **關** |
| **Traction Control（循跡控制）** | **必關** |
| **變速箱** | **至少 Manual Clutchless（手動無離合）** |
| Manual with Clutch（手動有離合） | 額外好處：可以 **clutch kick**，但新手非必要 |
| **Auto（自動排檔）** | **極難漂移**——還沒學手動的話現在就是學的時機 |
| **Steering（轉向）** | **Normal**，新手建議 |
| **ABS** | 新手保留即可 |

## 五、漂移技巧

漂移 = **四個部分**：
1. **Line**（路線）
2. **Entry**（入彎）
3. **Drift**（中段）
4. **Exit / Transition**（出彎或過渡到下一彎）

作者選**主節慶區的 Drift Zone**當練習場。

### 5.1 手煞車入彎（新手起手式）

> 手煞車入彎是「新手拐杖」——容易上手，但熟練後要學會減少使用手煞車。

#### 步驟

1. 直線朝彎切入
2. **轉向 + 同時拉手煞車**
3. **手煞車保持拉住** + **看到車重轉移就立刻反打（counter-steer）**
4. **不要碰油門**——只用手煞車與反打維持在彎中前進，直到停下來
5. 全程**車頭朝彎道出口**

#### 自我診斷

| 結果 | 診斷 |
|------|------|
| 停下來時與橋平行 | 大概做對了 |
| 持續打轉（spin out） | **反打太晚 / 反打不夠** |
| 入彎太快 / 太外 | **手煞車拉太多** |

#### 加油時機

能穩定不打轉之後，**才開始加油**——而且**只在需要時加**：

- 速度自然慢下來、滑了一下後 → 加油拉回來、推出彎
- 加油就撞紅線 → **檔位太低**，升檔
- 加油就 bog down → **檔位太高**，降檔

### 5.2 反打（counter-steer）

無法系統化教，**靠 timing + 練習**。要點：

- 你會慢慢學會預判：**入彎時車會走多大角度**
- 預判後，**幾乎要先反打、不是事後反打**
- 新手最常見錯：**反打太晚**——車已經太深 spin 中，救不回來

### 5.3 出彎與過渡

| 動作 | 結果 |
|------|------|
| 油門突然放掉 | 抓地突然回來 → 車身重量甩過去 → spin out |
| 油門緩慢放 / 半油門過渡 | 重量平順轉移 |

### 5.4 練習法

1. 找**一個彎反覆練**到幾乎每次都能 nail 為止
   - 入彎速度／角度
   - 何時加油
   - 何時反打
   - 怎麼跟線
2. 練熟換**地圖另一區**，嘗試**串連多個彎**
3. 連續彎熟練後，把**手煞車入彎**改成**重量轉移入彎**（weight shift entries）

### 5.5 手煞車的角色

別只當入彎工具——**漂移中段也能用**：在你需要延長 drift／補抓地不足時鎖住輪子。

### 5.6 核心心法：**「方向盤不是你的方向盤，油門才是」**

| 動作 | 效果 |
|------|------|
| **多油** | 增速 + 增加角度 + 把車推到彎外 |
| **腳煞** | 降速 + 把車拉到彎內 + 削 wheel speed |
| **手煞車** | 容易鎖死後輪 + 在需要時延長 drift |

## 六、排錯

> 「**90% 漂移問題能用更好的油門控制 + 反打解決。**」

### 6.1 build 層級

| 症狀 | 處方 |
|------|------|
| **新手一直 spin out** | **先加 grip** 直到舒服，再慢慢拿掉 |
| 完全不滑 | grip 太多，反向操作 |

### 6.2 想要**更多後抓地**

降低／放軟下列任一：

- 後 bump 阻尼
- 後彈簧剛性
- 後 ARB
- 後胎壓
- 差速器 accel / decel 鎖

### 6.3 想要**更少後抓地**

把上面**全部反向加硬**。

### 6.4 tandem 特殊考量

tandem 中常**故意促進更少抓地**——避免追車中突然抓回來而：
- 失去 drift
- 撞到 lead driver

## 七、結語

> **沒有比座位時間更值錢的 mod**（"no mod is more valuable than seat time"）。
> 漂移需要耐心，沒有按鍵組合可按；它是動態技能，要時間磨。
>
> 試不同車、不同 build、不同技巧——找到你的風格。**過彎沒有唯一正解**。
