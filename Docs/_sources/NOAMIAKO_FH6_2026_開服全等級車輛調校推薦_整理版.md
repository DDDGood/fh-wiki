## 概述

### FH6 駕駛手感變化

地平線六的駕駛感覺很難用一句話概括是「變難了還是變簡單」。NOAMIAKO 高強度試玩後最明顯的感受：**車的回饋變得更細膩**。

- **FH5**：開起來像輪胎吸著路面在跑，推頭、甩尾、抓地的恢復都來得比較突然。
- **FH6**：能明顯感覺到車身與懸吊的運動／變化；輪胎從抓地到打滑中間有更自然的過渡；車輛與地面的連結更加緊密。

在這樣優秀的物理引擎下，本影片整理出開服階段哪些車輛和調校有競爭力。

### 如何搜尋並套用本作者的調校（新手教學）

1. 進入車庫或嘉年華，選中車輛。
2. 打開「升級與調校」 → 「尋找調校設置」。
3. 創建者欄位輸入作者 ID：`NOAMIAKO`（原音「No amieo」）。
4. 搜到後下載安裝即可。
5. 若想之後更方便找，按 `X` 進入該作者的「創意中心」，再按 `Y` 點關注；系統之後會更容易推薦該作者的調校。

> 本影片所有車輛調校推薦都已收錄到作者的線上調校表格，後續更新也會同步至表格。表格連結需透過私訊取得。

## 八、特別說明

1. **取得方式中的「車展與抽獎」** = 嘉年華車展（Car Pass / Wheelspin），可隨遊玩自然累積。
2. **「全熱熔／半熱熔」**：全熱熔（Race Slick）僅限乾燥路面；半熱熔（Sport Compound）可在輕度積水路面駕駛。
3. **「直線胎」**：對應遊戲內 Drag Tire；超強縱向抓地，但僅限乾燥路面，且橫向抓地犧牲。
4. **「拉力胎／越野胎／雪地胎」**：不同地形對應不同胎系，調校時搭配遊戲內地形偏好。
5. **「四驅／後驅」**：影片大量出現「四驅 vs 大馬力後驅」對比，後者通常彎速高、控車難度高，前者通常入門友善。
6. **車型還原備註**：部分車型名稱因語音辨識誤差，已依 FH 系列既有車庫與上下文還原；少數仍標註「（原音近似）」以便讀者在實際進入遊戲後比對車庫名稱。
