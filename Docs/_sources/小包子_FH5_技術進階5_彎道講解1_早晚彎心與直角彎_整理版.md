## 一、彎心（Apex）概念

### 1. 內側三段分法

把一個彎道的**內側**分為三段：

| 段位 | 位置 | 走這段 = 走的路線 |
|------|------|------------------|
| **早彎心段** | 靠近入彎那一段 | 早彎心路線（重視入彎） |
| **正常彎心段** | 中間那一段 | 正常路線（外內外） |
| **晚彎心段** | 靠近出彎的一段 | 晚彎心路線（重視出彎） |

通過彎道時切的是哪個區域的彎心，就是走的什麼樣的路線。

### 2. 三類過彎路線

#### 早彎心（重視入彎）

- **特徵**：入彎速度快、出彎速度慢
- **適用場景**：
  - 超車
  - 出彎後直線較短，緊接連續彎的情況
- **適用環境較少，較少能看見**
- **範例**：瞭望台環島最後的掉頭彎

#### 晚彎心（重視出彎）

- **特徵**：捨棄入彎速度，換取更快的出彎速度
- **適用場景**：出彎後有拼速度的長直線時
- **範例**：黃金驛站的一號彎
  - 這個彎道走晚彎心走得好，可以在大直線上拉開**非常可觀**的差距

#### 正常路線（外內外）

- **適用**：在不知道前後情況時的預設選擇
- 速度自然是最快的

> 💡 早晚彎心是要**適配賽道**進行使用的；不知道前後情況時，走正常的「外內外」就是最快的。

## 二、為什麼外內外最快？（輪胎極限原理）

很多人知道「外內外最快」，但**原理並不了解**。原理跟**輪胎的極限**有關：

### 抓地過彎的物理規律

| 情況 | 結果 |
|------|------|
| 越接近輪胎極限的區間 | 通過時間越短 |
| 通過路線**越順滑** | 輪胎可承受**越高的速度**通過 |
| 通過路線**越有稜有角** | 需要**越低的速度**通過 |

### 突破輪胎極限的兩種表現

| 突破位置 | 車輛表現 | 駕駛感 | 通常成因 |
|---------|---------|--------|---------|
| **前輪**極限被突破 | 推頭（understeer） | 感覺車子拐不過去 | **入彎速度過快** |
| **後輪**極限被突破 | 甩尾（oversteer） | 感覺車子一下子拐過了 | **油門或重心轉移**出了問題 |

> 出現任何一種，代表這個彎過得有問題。

→ 結論：**過彎路線越順滑，且能切到彎心是最好的**。

## 三、直角彎拆解

> 由於篇幅問題，本期視頻只做**直角彎**的講解。

把直角彎分為三個主要會出錯的地方：

1. 減速
2. 入彎（路線）
3. 出彎

### 1. 減速階段：煞不住車的兩種情況

#### 情況 A：煞車點太遲，距離不夠減速

**判斷煞車點**：通常可以根據**輔助線**判斷。

> 當車頭到達輔助線的**紅區**時，應立刻減速。
>
> 通常都是準確的，可以用這個來找感覺。

#### 情況 B：煞車過程中後輪打滑

成因：

- 降檔速度過快
- 亂動方向

→ 導致後輪打滑，無法發揮出最佳的煞車效率。

**解法**：

- 減速時**盡量少拖檔**
- 煞車過程中**盡量少打方向**
- 打方向也要在**重煞快結束時**進行

這樣就能讓煞車效率一直保持在較高的區間。

### 2. 入彎路線：標準外內外

正常路線肯定是走**外內外**最快：

| 階段 | 動作 |
|------|------|
| 入彎時 | 盡量靠著**外側**進行煞車 |
| 減速完成後 | 入彎切彎心 |
| 車頭對準出彎處 | 開始給油 |
| 切過彎心後 | **可以開始含半油** |
| 車頭快對準出彎位後 | **可全油推出** |
| 過彎心後 | 路線慢慢往外靠 |

> 目標：**保證輪胎在抓地力極限內進行最快的加速**。

### 3. 出彎控油

> 四驅車出彎加速時，**可以允許小幅度的打滑**。

這個小幅打滑的好處有兩個：

1. 沒有讓車子失控的前提下，**讓輪胎處於抓地力的極限狀態**
2. 可以**保證引擎在高轉速區間**，動力最大化

### 4. 直角彎走法：早晚彎心差異不大

直角彎走早彎心和晚彎心**其實沒有什麼太大的區別**——

> 基本上**除非是組合彎**，直角彎都用正常的**外內外**來走就行了。

### 5. 直角彎核心：煞車

> 直角彎這裡看大家最大的問題就是**煞車時的問題**——
>
> **弄好煞車就已經完成了 50% 了。**
